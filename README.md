## نبذة عني

<div dir="rtl" align="right">

أنا **محمد الحناني**، مهندس برمجيات ومطور Full Stack، أركز على بناء تطبيقات ويب وأنظمة أعمال وحلول رقمية تجمع بين تجربة المستخدم الجيدة، والبنية الخلفية المنظمة، وقابلية التوسع.

- **التعليم:** بكالوريوس تكنولوجيا المعلومات، جامعة GIC — صنعاء، 2022.
- **الإنجاز الأكاديمي:** المركز الأول على مستوى الكلية في مشروع التخرج.
- **مجالات العمل:** تطبيقات الويب، الأنظمة الخلفية، واجهات API، قواعد البيانات، وتطبيقات الجوال.
- **منهجية العمل:** كتابة كود قابل للصيانة، اختيار التقنية المناسبة، والاهتمام بالأداء والأمان.

</div>
