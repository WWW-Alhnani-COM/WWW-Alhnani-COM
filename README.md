## 👨‍💻 نبذة عني

<div align="right" dir="rtl" style="font-size:18px; line-height:1.8; max-width:900px; margin:20px auto; padding:25px; background:linear-gradient(135deg, #667eea 0%, #764ba2 100%); color:white; border-radius:20px; box-shadow:0 10px 30px rgba(0,0,0,0.3);">

أنا **مهندس برمجيات | مطور Full Stack** متخصص في بناء تطبيقات ويب وتطبيقات جوال متكاملة.  
حاصل على المركز الأول على مستوى الكلية لمشروع التخرج.  
أمتلك خبرة في تطوير تطبيقات الويب والجوال وسطح المكتب، مع مهارات في **Microservices، Docker، Kubernetes، PostgreSQL، MongoDB، Redis**.  
أتعلم بسرعة ولدي قدرة عالية على العمل الجماعي والعمل عن بُعد.

### 🎯 مجالات التخصص:
- **تطوير واجهات المستخدم الحديثة** باستخدام React.js، Angular، Bootstrap
- **تطوير الأنظمة الخلفية** باستخدام .NET Core، Node.js، Laravel
- **تصميم تجربة المستخدم** (UI/UX) لتطبيقات متميزة
- **تطوير تطبيقات الجوال** باستخدام Flutter و Firebase
- **الخدمات السحابية** (AWS, Azure) والحلول الموزعة
