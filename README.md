## 👨‍💻 نبذة عني

أنا **محمد الحناني**، مهندس برمجيات ومطور Full Stack أعمل على تصميم وتطوير تطبيقات الويب والجوال وأنظمة الأعمال، من الواجهات وتجربة المستخدم إلى الخدمات الخلفية وقواعد البيانات والنشر.

- 🎓 بكالوريوس تكنولوجيا المعلومات — جامعة GIC، صنعاء (2022).
- 🏆 المركز الأول على مستوى الكلية في مشروع التخرج.
- 🧩 خبرة في بناء واجهات API والأنظمة المترابطة والتطبيقات متعددة الطبقات.
- ☁️ اهتمام بالهندسة السحابية، الحاويات، الأتمتة، والأداء وقابلية التوسع.
- 🤝 أؤمن بالتواصل الواضح، والتعلم المستمر، وتحويل احتياجات العمل إلى حلول عملية.
